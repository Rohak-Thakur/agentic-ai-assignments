


# Agentic AI Assignments

This repository contains a collection of hands-on assignments focused on Agentic AI, autonomous systems, and intelligent decision-making workflows. The projects explore how agents reason, plan, adapt to constraints, and solve practical tasks using structured approaches such as reflex agents, goal-based planning, utility-based decision-making, and LLM-driven reasoning strategies.

The work in this folder is intended for learning, experimentation, and academic exploration in the field of agentic artificial intelligence.

## Overview

Agentic AI is the study of systems that can:
- perceive their environment,
- reason about goals and constraints,
- plan actions,
- interact with tools and data,
- adapt to changing situations,
- and complete tasks with minimal human intervention.

This repository demonstrates these ideas through multiple assignments, each covering a different perspective of agent behavior and autonomy.

## Included Assignments

### 1) Agentic_AI-1
This folder contains the first assignment focused on agent architectures and autonomous decision-making.

It explores:
- Simple Reflex Agents
- Model-Based Reflex Agents
- Goal-Based Agents
- Utility-Based Agents

The notebook simulates a vacuum-cleaning grid world and compares different agent strategies based on:
- steps taken,
- task completion rate,
- robustness under dynamic changes,
- battery/resource efficiency.

### 2) Agentic_AI-2
This assignment focuses on autonomous trip planning using LLM-based reasoning strategies.

It compares:
- Chain-of-Thought (CoT)
- Tree-of-Thought (ToT)
- ReAct (Reason + Act)

The scenario includes a real-world planning task:
- Delhi to Mumbai trip
- 3-day / 2-night itinerary
- 3 travelers
- Budget constraint
- Mid-task budget reduction
- Realistic travel and accommodation planning

This assignment highlights how different reasoning styles behave under constraints and changing conditions.

### 3) Agentic_AI-3
This folder is reserved for additional assignment work related to Agentic AI and autonomous systems. It may contain future coursework or lab exercises.

### 4) Agentic_AI-4
This folder is reserved for further practical or academic tasks in the same domain. It may include additional implementations, experiments, or advanced agent-based scenarios.

### 5) JURY-1
This folder contains a Smart Event Analytics Agent notebook focused on technical club performance analysis.

The project demonstrates an agentic workflow involving:
- understanding the user goal,
- gathering event-related data,
- validating missing or inconsistent information,
- computing deterministic performance metrics,
- ranking clubs based on participation and quality,
- generating an interpretable final report.

It showcases how agentic systems can be used for analytics, planning, and structured decision support.

## Setup

To run the notebooks:

1. Open the project in VS Code or Jupyter Notebook.
2. Create and activate a virtual environment if needed.
3. Install the required Python dependencies:
   ```bash
   pip install numpy pandas matplotlib python-dotenv
   ```
4. For notebooks requiring LLM APIs, configure the relevant API keys in the `.env` file.
5. Run the notebooks cell by cell in order.
